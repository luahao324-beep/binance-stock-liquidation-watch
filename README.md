# 币安股票合约急跌监控 Skill

帮助 Codex 检查股票现货休市期间，币安股票永续合约的异常急跌、集中多头清算证据，以及随后修复或继续下跌的情况。

默认研究范围：海力士、美光、闪迪、三星。支持按用户要求扩展，使用前核对合约状态及市场日历。

## 能做什么

- 获取公开行情，按固定条件识别急跌。
- 分清“价格异常”和“清算已确认”，避免将成交额当成清算额。
- 回放历史，记录修复和失败案例。
- 为持续监控整理规则、配置及部署要求。

安装 Skill 不会自动启动常驻程序、发送通知或进行交易。内置扫描脚本只处理本地行情数据，不连接网络、不下单。

## 安装到 Codex

下载仓库 ZIP 并解压，将包含 `SKILL.md` 的文件夹命名为 `binance-stock-liquidation-watch`，放到个人 Skills 目录：

```text
~/.codex/skills/binance-stock-liquidation-watch/
```

使用自定义 `CODEX_HOME` 时放在其 `skills/` 子目录。让 Codex 重新加载技能后调用。

## 调用示例

```text
使用 $binance-stock-liquidation-watch 检查币安股票合约有没有休市急跌。
```

```text
使用 $binance-stock-liquidation-watch 回放过去八个周末，保持默认规则不变，统计报警后继续下跌与修复情况。
```

实时行情需要可用的 Binance 只读连接器或官方公开 API。历史回放也可以使用符合格式的本地数据。公开行情不需要提供交易密钥。

## 默认规则

完整分钟收盘相对五分钟前下跌至少 2%，同时该分钟成交额至少为前 60 个完整分钟均值的 5 倍，且不少于 10 万 USDT。只在已确认的休市窗口检查。严重跌幅、清算确认及修复状态分别处理。

阈值是候选异常筛选条件，不是已验证的盈利策略。周末急跌并不保证周一回正。

## 本地扫描

```sh
python3 scripts/scan.py data.json --start 2026-10-10T04:00:00Z --end 2026-10-11T20:00:00Z --output result.json
```

输入格式见数据说明，需要至少 60 分钟预热数据。原始 Binance K 线应先转换为指定六字段格式。

当前发布包不包含个人配置、API 密钥或原始历史行情。持续监控、通知投递和自动交易不包含在此扫描脚本内。
